How to use

  1. Paste a patient note (or load a held-out sample). Sentences are numbered 0, 1, 2…; the model cites these IDs.
  2. Choose a sample trial, fetch one by NCT id (needs internet), paste an eligibility block, or add criteria manually.
  3. Pick a decoding mode and press Screen patient. Each criterion gets a label, cited sentences, and an explanation that only restates cited text.
  4. Export a report (HTML/Markdown/JSON) with model, adapter hash, decoding settings and timestamp.

Labels

Inclusion: included, not included, not enough information, not applicable. Exclusion: excluded, not excluded, not enough information, not applicable. A missing mention is never converted into eligibility or ineligibility.

Overall outcome rule

"Likely not eligible" if any inclusion is not included or any exclusion is excluded; otherwise "Needs more information" if any criterion is not enough information (or the output was invalid); otherwise "Potentially eligible". This is an explicit aggregation rule, not a labelled ground-truth outcome.

Limits

Small 360M-parameter model, 603 training annotations, English notes of a few sentences. See the paper for measured accuracy.
